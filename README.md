# SPOCC
Project SPOndyliosoma Cantharus in the Channel (SPOCC) was financed by FEAMPA, under the direction of the Organisation des Pêcheurs Normands (OPN) and the Institut Français pour la Recherche et l'Exploitation de la Mer (IFREMER). 

Branches : 
- Giffs: Animated maps and data figures from commercial landings (Ifremer's SIH SACROIS database) or scientific surveys (ICES's DATRAS)
- Maturity : All R codes used to analyse sexual maturity data
