# SPOCC
SPOndyliosoma Cantharus in the Channel

# 05_OUTPUTS

This directory contains the outputs generated by the analyses performed in the `sdmTMB_index` folder

## Contents

Outputs may include:

- Model results: Fitted `sdmTMB` models, model estimates and diagnostics
- Biomass indices: Estimated abundance indices and associated uncertainty
- Figures: Maps, plots and graphical summaries of model results
- Tables: Summary statistics and exported model results

## Output availability

Generated outputs are stored locally and excluded from version control via `.gitignore`
